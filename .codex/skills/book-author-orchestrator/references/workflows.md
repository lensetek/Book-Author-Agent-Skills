# Source Workflows

## From Idea To Book

1. Clarify discipline, audience, book type, and main promise.
2. Turn the idea into 5-10 core questions.
3. Build a concept map and identify missing literature.
4. Choose book type using `book-types.md`.
5. Create table of contents with chapter objectives.
6. Draft sample chapter or expanded synopsis.
7. Review citation gaps and assumptions.

Deliverables:

- project brief,
- concept map,
- proposed title/subtitle,
- table of contents,
- chapter synopsis,
- source acquisition list.

## From RPS To Buku Ajar

1. Extract course identity, description, CPMK, sub-CPMK, topics, references, assessments, and meeting schedule.
2. Group meetings into coherent chapters; do not force one meeting into one chapter if concepts are too small.
3. Map each chapter to CPMK/sub-CPMK.
4. Add learning objectives, key concepts, examples, exercises, assignments, and assessment prompts.
5. Check progression from prerequisite concepts to advanced application.
6. Review alignment among CPMK, chapter content, exercises, and evaluation.

Deliverables:

- RPS extraction table,
- CPMK-to-chapter matrix,
- teaching-oriented table of contents,
- chapter template,
- exercise and assessment plan.

## From Single Paper To Monograf

1. Extract title, research problem, context, theory, method, data, findings, contribution, limitation, and references.
2. Identify which parts can become chapters and which need expansion.
3. Expand literature context into state of the art.
4. Separate original findings from additional interpretation.
5. Add implications, limitations, and future research.
6. Mark all missing references and unverifiable claims.

Deliverables:

- paper-to-chapter map,
- monograph outline,
- state-of-the-art expansion plan,
- contribution statement,
- citation gap list.

## From Multiple Papers To Buku Referensi

1. Cluster papers by theme, theory, method, context, or finding.
2. Identify consensus, disagreement, gaps, and research trends.
3. Build chapters around themes, not around individual papers.
4. Add comparison tables and synthesis diagrams where useful.
5. Ensure each chapter has a clear conceptual contribution.
6. Mark weakly supported areas needing more sources.

Deliverables:

- literature cluster map,
- synthesis matrix,
- thematic table of contents,
- comparison table plan,
- missing source list.

## Mixed Source Workflow

Use a two-pass approach:

1. Inventory all sources and classify each as teaching, conceptual, empirical, administrative, or supporting material.
2. Choose the dominant book type, then use other sources as supporting material.

Default priority:

- If RPS is central, bias toward buku ajar.
- If one research project is central, bias toward monograf.
- If multiple papers or broad literature are central, bias toward buku referensi.
