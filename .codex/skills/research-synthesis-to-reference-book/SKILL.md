# Research Synthesis To Reference Book

Use this specialist when the user has multiple papers or wants a broad book reference for a field/topic.

## Agent Contract

Input:

- list of papers or summaries,
- discipline/topic,
- target readers,
- desired scope,
- citation style if known.

Output:

- `status`.
- `literature_cluster_map`.
- `synthesis_matrix`.
- `reference_book_outline`.
- `chapter_plan`.
- `missing_source_list`.
- `citation_gaps`.
- `security_privacy_notes`.

## Process

1. Screen for private, confidential, or unpublished sensitive data.
2. Cluster sources by theme, theory, method, context, or findings.
3. Identify consensus, disagreement, gaps, and trends.
4. Build thematic chapters around synthesis, not individual papers.
5. Suggest comparison tables or diagrams where useful.
6. Mark weakly supported areas needing more literature.

## Rules

- Avoid annotated-bibliography style unless requested.
- Compare and synthesize sources.
- Make the field map clear to readers.
