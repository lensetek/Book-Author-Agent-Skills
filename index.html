Security

Keamanan

No credentials in public output or frontend bundles. Tidak ada credential di output publik atau bundle frontend.

Every workflow begins and ends with security and privacy checks for API keys, student data, respondent identities, document metadata, and public frontend variables. Setiap workflow diawali dan diakhiri cek keamanan untuk API key, data mahasiswa, identitas responden, metadata dokumen, dan variable frontend publik.

  • API keys, tokens, passwords, `.env`, cloud credentials
  • Student data, grades, respondent identities, personal data
  • Frontend-exposed secrets: public JavaScript, source maps, `VITE_*`
  • Document comments, tracked changes, hidden text, metadata
